X-ray Hand Bone Image Segmentation

Data-Centric Approach & Hybrid Ensemble Strategy

2024.12 - 2025.01 Team CV-05 (4인) Role: AI Researcher & Model Optimization
Python 3.10 PyTorch SMP Docker WandB

1. 프로젝트 개요 (Overview)

X-ray 이미지에서 29개의 손 뼈를 픽셀 단위로 분할(Segmentation)하는 프로젝트입니다. 단순한 모델링을 넘어, 의료 데이터 특유의 Class Imbalance(클래스 불균형)와 Superimposition(뼈 중첩) 문제를 해결하기 위해 데이터 중심(Data-Centric)의 가설 검증 프로세스를 수행했습니다.

  • 성과: Private Leaderboard Dice Score 0.9752 (Rank 11, Top 10%)
  • 핵심 기여: Hybrid Ensemble 설계, 데이터 전처리(CLAHE) 최적화, Custom Loss 엔지니어링

2. 문제 정의 (The Challenge)

🔍 Why was it hard?

  • Class Collapse (소형 객체 소멸): 'Finger-12, 13'과 같은 미세 관절은 전체 픽셀의 0.01% 미만을 차지하여, 학습 시 배경(Background)으로 오분류되는 현상 발생 (Dice 0.00).
  • Ambiguity (경계 모호성): 3차원인 손목뼈(Carpal Bones)가 2차원 X-ray로 투영되면서 뼈끼리 겹치는 구간(Overlap)의 경계선이 불분명해짐.

3. 문제 해결 과정 (Engineering Process)

SOTA 모델을 맹신하지 않고, "보이지 않는 것을 보이게 만드는" 엔지니어링 접근을 시도했습니다.

🧪 Try 1: "안 보이는 뼈" 살려내기 (Data-Centric)

Situation: 512px 해상도와 원본 이미지로는 소형 뼈의 특징점(Feature)이 소실됨.

Action:

  • Resolution Scaling: VRAM 한계 내에서 정보 손실을 막기 위해 1024px 기반의 Progressive Resizing 도입.
  • Contrast Enhancement: CLAHE 및 Random Gamma Correction을 적용하여 뼈와 연조직 사이의 대비를 극대화.

Result: 소형 객체(Pisiform 등)의 Dice Score가 0.00에서 0.85 이상으로 급격히 상승.

⚙️ Try 2: "뭉개진 경계" 구분하기 (Model & Loss)

Situation: 손목뼈 중첩 구간에서 단순 BCE Loss는 픽셀 수가 많은 '배경' 쪽으로 편향되어 경계를 제대로 학습하지 못함.

Action:

  • Hybrid Ensemble: 국소적 특징(Edge)에 강한 CNN(HRNet)과 전역적 문맥(Context)을 보는 Transformer(MaxViT)를 결합하여 상호 보완적 앙상블 구축.
  • Loss Engineering: Focal Loss(Hard Example 집중) + Tversky Loss(Recall 보정)를 결합한 Compound Loss 설계.

Result: 중첩된 뼈 사이의 경계선 분할 정밀도(Precision) 대폭 향상.

4. 최종 결과 및 회고 (Results & Retrospective)

🏆 Final Score: Dice 0.9752

1위(0.9769)와 0.0017 차이의 접전. 모델 성능은 대등했으나, Post-processing(후처리)의 디테일이 승부를 갈랐음을 확인했습니다.

💡 Lessons Learned (Analyical Thinking)

  • Data First, Model Second: 아무리 좋은 SOTA 모델도 데이터(전처리)가 받쳐주지 않으면 무용지물임을 깨달음. 특히 의료 데이터에서는 도메인 지식에 기반한 전처리가 성능의 8할을 결정함.
  • Validation Strategy: Group K-Fold를 통해 '왼손/오른손' 데이터 유출(Leakage)을 막고, Public LB와 괴리 없는 신뢰할 수 있는 검증 세트를 구축하는 것의 중요성 체감.
  • Engineering Trade-off: 0.001점을 올리기 위해 무거운 앙상블을 사용했으나, 현업 배포를 고려한다면 Knowledge Distillation과 같은 경량화 전략이 필수적임.
