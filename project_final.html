AWS(Web)와 On-Premise(GPU)를 연결한 Hybrid Cloud 아키텍처 시연 (5배속)

Core Tech & Tools

FastAPI PostgreSQL AWS EC2 SSH Tunneling LangChain (RAG) Docker Flutter

Key Engineering Achievements (STAR)

1. Hybrid Cloud 구축을 통한 비용 최적화 및 보안 문제 해결

Situation: 학생 프로젝트 예산상 시간당 고비용의 Cloud GPU 인스턴스(AWS g4dn 등)를 유지하기 어려웠으며, 로컬 고성능 GPU(RTX 3060)를 활용하려 했으나 유동 IP 및 방화벽 문제로 외부 접속이 제한되었습니다.

Task: 추가 비용 없이(Zero-Cost) 로컬 GPU 자원을 안전하게 클라우드 환경과 연동하여 고성능 추론 서버를 구축해야 했습니다.

Action:

  • SSH Reverse Tunneling 설계: 로컬 서버가 AWS EC2를 향해 Outbound 터널(`ssh -R`)을 먼저 형성하여, 외부 포트 개방 없이 안전한 통신 경로를 확보했습니다.
  • Network Troubleshooting: 터널링 연결 시 `curl: (52) Empty reply` 오류가 발생함을 확인하고, 원인이 IPv6(`localhost`) 해석 문제임을 규명했습니다. 이를 `127.0.0.1`로 강제 매핑하여 통신을 안정화했습니다.

Result: 클라우드 비용을 최소 유지비 수준(t3/m7i)으로 절감하면서도 RTX 3060의 추론 성능을 온전히 활용하는 하이브리드 파이프라인을 완성했습니다.

2. 비동기 백엔드 아키텍처 및 협업 환경 구축

Situation: AI 모델의 추론 지연 시간과 대용량 이미지 처리가 발생하여 단일 스레드 방식으로는 응답성이 저하될 우려가 있었습니다. 또한, 프론트엔드 팀과의 협업을 위한 명확한 API 명세가 부재했습니다.

Task: 고성능 비동기 처리가 가능한 서버를 구축하고, 효율적인 협업을 위한 API 테스트 환경을 제공해야 했습니다.

Action:

  • FastAPI & Async SQLAlchemy: `uvicorn` 기반의 비동기 서버를 구축하여 I/O 블로킹을 최소화하고, Layered Architecture(Router-Service-Schema)를 적용해 유지보수성을 높였습니다.
  • Swagger UI 고도화: 기존의 번거로운 폼 데이터 인증 방식을 개선하기 위해 `HTTPBearer` 방식을 도입, Access Token만으로 즉시 테스트 가능한 환경을 프론트엔드 팀에 제공했습니다.

Result: 프론트엔드-백엔드 간 연동 시행착오를 줄이고, 안정적인 데이터 처리 파이프라인을 구축했습니다.

3. RAG 기반의 개인화된 의료 상담 시스템 구현

Situation: AI 모델이 출력하는 단순 수치(심각도 1~6, 구진 개수 등)만으로는 사용자가 구체적인 행동 지침을 얻기 어려웠고, 일반 LLM은 의학적 환각(Hallucination) 위험이 있었습니다.

Task: 진단 결과에 맞춰 의학적 근거가 있는 신뢰성 높은 맞춤형 조언을 제공해야 했습니다.

Action:

  • Context Injection Pipeline: YOLO와 MobileNet의 분석 결과(JSON)를 텍스트 프롬프트로 정형화하여 LangChain의 Context로 주입했습니다.
  • RAG System Integration: 검증된 피부과 의학 가이드라인 문서를 Vector DB에 적재하고, 사용자 상태에 맞는 문맥을 검색하여 답변을 생성하도록 설계했습니다.

Result: "심각도 4단계이므로 항생제 처방이 필요할 수 있습니다"와 같이 사용자 상태에 최적화된 구체적이고 신뢰성 있는 의료 가이드를 제공했습니다.

Project Outcome

  • Full Pipeline 구축: Flutter(앱) - AWS(서버) - Local(AI) - DB로 이어지는 End-to-End 서비스 완성
  • 비용 효율성 극대화: 클라우드 비용을 최소 유지비(EC2 t/m시리즈) 수준으로 절감하며 GPU 자원 활용
  • 사용자 중심 기능: 객관적 수치(KGS 등급) 제공 및 즉각적인 의료 가이드라인 제시로 1차 스크리닝 도구로서의 가치 입증
