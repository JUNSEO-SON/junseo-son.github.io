AWS(Web)와 On-Premise(GPU)를 연결한 Hybrid Cloud 아키텍처

Core Tech & Tools

FastAPI PostgreSQL AWS EC2 SSH Tunneling LangChain (RAG) Docker Flutter

My Role: Backend Lead & Architect

Hybrid Cloud Pipeline 구축

고비용의 Cloud GPU 대신 AWS EC2(Web)와 Local GPU(Inference)를 SSH Reverse Tunneling으로 연결했습니다. 이를 통해 클라우드 비용을 최소화하면서도 RTX 3060의 고성능 추론 자원을 활용하는 파이프라인을 완성했습니다.

FastAPI Server & DB Engineering

비동기 처리가 가능한 FastAPI를 기반으로 인증(Auth), 진단(Diagnosis), 결과 저장 로직을 설계했습니다. PostgreSQL 스키마를 최적화하여 사용자 데이터와 AI 분석 결과를 효율적으로 적재하고 관리했습니다.

RAG Agent Integration

단순 진단 점수 제공을 넘어, LangChain을 활용한 RAG(Retrieval-Augmented Generation) 시스템을 백엔드에 통합했습니다. 진단 결과(Severity Grade)에 맞춰 의학 가이드라인 기반의 맞춤형 관리법을 제공하는 로직을 구현했습니다.

Engineering Challenges

Challenge

클라우드 GPU 비용 문제와 보안 접근성

학생 프로젝트 예산으로 고성능 GPU 인스턴스를 유지하기 어려웠고, 로컬 서버는 외부 접속(Public IP) 설정이 복잡하고 보안 취약점이 존재했습니다.

Solution: SSH Reverse Tunneling

로컬 서버가 AWS EC2를 향해 Outbound SSH 터널을 먼저 형성하게 하여 방화벽 문제를 해결했습니다. 외부 요청은 AWS가 받아 터널을 통해 로컬 포트(localhost:8002)로 안전하게 포워딩하는 구조로, 비용 '0원'으로 고성능 서빙 환경을 구축했습니다.

Challenge

AI 결과의 신뢰성 및 정형화 문제

AI 모델의 결과(JSON)만으로는 사용자에게 구체적인 행동 가이드를 주기 어려웠고, LLM의 환각(Hallucination) 위험이 있었습니다.

Solution: Structured RAG Pipeline

YOLO와 MobileNet의 분석 결과(구진/결절 개수, 심각도)를 Context 데이터로 정형화하여 Prompt에 주입했습니다. 검증된 의학 문서를 참조하는 RAG 시스템을 통해, "심각도 4단계이므로 항생제 처방이 필요할 수 있습니다"와 같은 구체적이고 신뢰성 있는 조언을 생성했습니다.

Project Outcome

  • Full Pipeline 구축: Flutter(앱) - AWS(서버) - Local(AI) - DB로 이어지는 End-to-End 서비스 완성
  • 비용 효율성 극대화: 클라우드 비용을 최소 유지비(EC2 t/m시리즈) 수준으로 절감하며 GPU 자원 활용
  • 사용자 중심 기능: 객관적 수치(KGS 등급) 제공 및 즉각적인 의료 가이드라인 제시로 1차 스크리닝 도구로서의 가치 입증
