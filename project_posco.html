POSCO 현직자 기술 멘토링

설비 고장 이력 자동 분류를 위한 RAG 파이프라인 설계 가이드

Overview

포스코그룹의 'AI 활용 전문가 과정'에서 기술계 코치로 활동하며, 현직자 팀이 진행하는 '설비 고장 이력 키워드 자동 분류' 프로젝트를 기술 멘토링했습니다. 도메인 지식은 풍부하지만 AI 엔지니어링 경험이 부족한 현직자들에게 벡터 DB와 LLM을 활용한 RAG 아키텍처를 제안하고, 데이터 전처리 로직 최적화를 가이드했습니다.

The Problem

  • 비효율성: 매주 1,300건의 설비 고장 데이터를 엑셀로 수작업 분류하느라 주당 7시간이 소요됨.
  • 정합성 문제: 작업자마다 주관적인 기준으로 분류하여 데이터의 일관성이 떨어지고 분석 왜곡 발생.

Solution (My Contribution)

1. RAG 아키텍처 설계 가이드

단순 LLM 호출이 아닌, 사내 데이터를 Vector DB에 임베딩하여 검색하는 RAG(Retrieval-Augmented Generation) 방식을 제안하여 할루시네이션을 줄이고 정확도를 높였습니다.

2. 데이터 전처리 최적화

비효율적인 반복문으로 작성된 전처리 코드를 진단하고, Pandas 벡터화 연산을 활용한 최적화 코드를 스니펫(Snippet) 형태로 제공하여 처리 속도를 개선했습니다.

Lesson Learned

직접 코드를 짜는 것보다 타인의 코드를 리뷰하고 올바른 방향으로 이끄는 것이 더 높은 차원의 이해도를 요구한다는 것을 배웠습니다. 특히, 비전공자인 현직자에게 기술적 개념(Vector DB, Embedding)을 비즈니스 언어로 번역하여 설명하는 '기술 커뮤니케이션' 역량을 기를 수 있었습니다.
