GongPick: 공무원 업무추진비 기반 맛집 추천

비정형 텍스트 데이터 분석 및 Azure 클라우드 기반 서비스 배포

GitHub Repo

My Role

  • Modeling: 데이터 전처리 및 추천 알고리즘 구현. SVD와 콘텐츠 기반 필터링을 결합한 하이브리드 추천 시스템 개발.
  • Deployment: Azure Web App 기반 배포 파이프라인 구성. GitHub Actions를 활용한 CI/CD 구축 및 자동 배포 환경 마련.
  • API: FastAPI를 활용한 백엔드 API 서버 개발. RESTful API 설계 및 문서화(Swagger UI), 프론트엔드 연동 최적화.

Development Process

1. 데이터 수집 및 전처리

공공데이터 포털의 업무추진비 CSV 데이터를 수집. 가게명, 주소, 금액 등의 비정형 텍스트에서 불용어를 제거하고 정규화(Normalization) 수행.

2. 모델링 및 API 개발

사용자 위치 및 예산 기반 필터링 로직 구현. FastAPI로 RESTful API를 설계하여 프론트엔드와 통신.

3. 클라우드 배포 (Azure)

Azure App Service를 활용하여 웹 애플리케이션을 배포. CI/CD 개념을 적용하여 코드 변경 사항을 반영.

Lesson Learned

로컬 환경에서의 개발과 클라우드 환경에서의 배포는 환경 변수 설정부터 네트워크까지 완전히 다름을 경험했습니다. 특히, Docker와 같은 컨테이너 기술의 필요성을 절감했고, 팀원들과의 협업을 위해 Git Flow를 준수하는 것이 코드 안정성에 얼마나 중요한지 깨달았습니다.
